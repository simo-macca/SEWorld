# SEWorld Frontend

The frontend for the SEWorld project, built with **Vue 3**, powered by **Vite**, and styled with **Bootstrap**. State management is handled by **Pinia**.

## Tech Stack
* **Framework:** Vue 3 (Composition API)
* **Build Tool:** Vite
* **State Management:** Pinia
* **Routing:** Vue Router
* **Styling/UI:** Bootstrap 5 & Bootstrap Vue Next
* **Data Visualization:** Chart.js + Vue-Chartjs
* **Markdown:** md-editor-v3

## Recommended IDE Setup
* [VSCode](https://code.visualstudio.com/)
* [Vue - Official (formerly Volar)](https://marketplace.visualstudio.com/items?itemName=Vue.volar) extension (ensure Vetur is disabled).

## Project Setup

Make sure you have [Node.js](https://nodejs.org/) and [Yarn](https://yarnpkg.com/) installed.

Install project dependencies:
```bash
yarn install
```

### Compile and Hot-Reload for Development

Starts the Vite development server on port `3000`.

```bash
yarn dev
```

### Compile and Minify for Production

Builds the app for production to the `dist` folder.

```bash
yarn build
```

### Preview Production Build

Locally preview the production build.

```bash
yarn preview
```
